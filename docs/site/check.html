Check your lock file

Paste or drop the lock file of your project. The page finds your LLM instrumentation libraries and shows what the nightly spantruth run found for those exact versions: which checks fail, which bug class each one is, and the release that fixes it.

Your file stays in your browser. This page reads it here and sends it nowhere. Its only request loads the published table, versions.json. It has no third-party script, no analytics and no cookies.

For a full answer, run doctor on your machine

The table covers the last releases of each library, each one run with spantruth's own pins for the other packages. doctor runs your exact versions together, on your machine, against a local fake provider:

uvx spantruth doctor

It reads the same lock files, and it never runs your application code. How it works.
